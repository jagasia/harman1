View encapsulation:

	a component, uses "styleUrl" this file is used only in this component
	we can modify the encapsulation level using "encapsulation" attribute and set it as global

1) shadowDOM
2) none		global
3) emulated	default		scoped to current component


  encapsulation: ViewEncapsulation.Emulated



@Component({
  selector: 'app-hello',
  templateUrl: './hello.component.html',
  styleUrls: ['./hello.component.css'],
  encapsulation: ViewEncapsulation.Emulated
})

can we create our own custom directive?

ex:

import { Directive, ElementRef, HostListener, Input } from '@angular/core';

@Directive({
  selector: '[highlight]'
})
export class Highlight {
@Input() highlight:string='yellow';

  constructor(private el:ElementRef) { }

 
  @HostListener('mouseenter') onEnter() {
    this.el.nativeElement.style.backgroundColor = this.highlight;
  }

  @HostListener('mouseleave') onLeave() {
    this.el.nativeElement.style.backgroundColor = '';
  }

}






to use this in other components, import this directive


import { Component } from '@angular/core';
import { Highlight } from './highlight';

@Component({
  selector: 'app-root',
  imports: [Highlight],
  templateUrl: './app.html',
  styleUrl: './app.css'
})
export class App {
  protected title = 'forms-demo';
}




and then use in html

<h1 [highlight]="'blue'">This is heading 1</h1>
<p highlight="green">This is a paragraph</p>
