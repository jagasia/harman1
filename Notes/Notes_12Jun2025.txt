ReactJs Routing
------------------
We need routing to redirect across components,
render component by
	re-writing url
	clicking a link
	clicking a button
	conditionally (if condition true, redirect to admin, else to user)

It is different from hyperlink. Hyperlinks redirect to a web page.
But, here, we redirect to a component.
	

1) How can we implement routing in reactjs?
	we need to install react-router-dom
		npm i react-router-dom

2) we need to cover the componet(s) where we want to define routes.
	i usually cover the <App> in index.js
		so that, all its children at any level are covered

	<BrowserRouter>
		<App />
	</BrowserRouter>

3) we define the routes....
	<Routes> is a placeholder, where the component will render.

	<Routes> component allows us to define each route and map it to the corresponding element

	<Routes>
		<Route path="" element="" />
	</Routes>

4) we can render a particular component by
	re-writing url
	clicking a link
	clicking a button
	conditionally (if condition true, redirect to admin, else to user)


Now, observe that, so far, if we want to render a component,
we plugged it in parent component.

For example, in App component, we plugged, Login component
But to dynamically render different components, based on condition etc, we need routing

Demo for routing:
-------------------
lets create the following components:
	Home
	About
	Contact
	Login
	Signup

1) we may use <BrowserRouter> in App component
or we may surround <App> by <BrowserRouter> in main.jsx

import 'bootstrap/dist/css/bootstrap.min.css'
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { BrowserRouter } from 'react-router-dom'
import App from './App.jsx'
import './index.css'

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>,
)



<Routes>
            <Route path='/home' element={<Home />} />
            <Route path='/about' element={<About />} />
            <Route path='/contact' element={<Contact />} />
            <Route path='/login' element={<Login />} />
            <Route path='/signup' element={<Signup />} />

          </Routes>
