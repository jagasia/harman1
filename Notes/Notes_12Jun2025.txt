ReactJs Routing
------------------
We need routing to redirect across components,
render component by
	re-writing url
	clicking a link
	clicking a button
	conditionally (if condition true, redirect to admin, else to user)

It is different from hyperlink. Hyperlinks redirect to a web page.
But, here, we redirect to a component.
	

1) How can we implement routing in reactjs?
	we need to install react-router-dom
		npm i react-router-dom

2) we need to cover the componet(s) where we want to define routes.
	i usually cover the <App> in index.js
		so that, all its children at any level are covered

	<BrowserRouter>
		<App />
	</BrowserRouter>

3) we define the routes....
	<Routes> is a placeholder, where the component will render.

	<Routes> component allows us to define each route and map it to the corresponding element

	<Routes>
		<Route path="" element="" />
	</Routes>

4) we can render a particular component by
	re-writing url
	clicking a link
	clicking a button
	conditionally (if condition true, redirect to admin, else to user)


Now, observe that, so far, if we want to render a component,
we plugged it in parent component.

For example, in App component, we plugged, Login component

----------------------------------------------------import { createContext, useContext, useState } from 'react';

const UserContext = createContext();

export const UserProvider = ({ children }) => {
  const [user, setUser] = useState(localStorage.getItem("user"));

  const login = (username) => {
    localStorage.setItem("user", username);
    setUser(username);
  };

  const logout = () => {
    localStorage.removeItem("user");
    setUser(null);
  };

  return (
    <UserContext.Provider value={{ user, login, logout }}>
      {children}
    </UserContext.Provider>
  );
};

export const useUser = () => useContext(UserContext);




import { useNavigate } from "react-router-dom";

import { useState } from "react";
import { useNavigate } from "react-router-dom";
import { useUser } from "./UserContext";

export const Login = () => {
  const [username, setUsername] = useState('');
  const [password, setPassword] = useState('');
  const navigate = useNavigate();
  const { login } = useUser();

  function fnLogin() {
    if (username === password) {
      login(username); // context-based login
      navigate('/adminhome');
    } else {
      login(username);
      navigate('/');
    }
  }

  return <>
    Username: <input type="text" className="form-control" onChange={(e) => setUsername(e.target.value)} />
    Password: <input type="password" className="form-control" onChange={(e) => setPassword(e.target.value)} />
    <br />
    <input type="button" value="Login" className="btn btn-info" onClick={fnLogin} />
  </>
}

class ProductService{
    URL="https://dummyjson.com/products";

    fnRetrieveAllProducts(){
        return axios.get(this.URL);
    }
}
export default new ProductService();

import { useEffect, useState } from "react";
import ProductService from "./services/ProductService";

export const ProductGrid=()=>{
    const [products, setProducts]=useState([]);

    useEffect(()=>{
        //call the api using service
        ProductService.fnRetrieveAllProducts()
        .then(response=>{
            console.log("Response received from api:");            
            console.log(JSON.stringify(response.data.products));            
            setProducts(response.data.products);
        })
        .catch(error=>{
            console.log("Error while accessing api...."+error);            
        })
    },[]);
    return <div>
        Product here...
        {
            products.map((p)=><li>{p.id}</li>)
        }
    </div>
}
