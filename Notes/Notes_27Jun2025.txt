if all endpoints are allowed access only after logging in, then how we will login? how we will signup??????

	specify what are all the endpoints allowed (permitAll)
	what other urls/ endpoints are authenticated


we specify these in a bean "securityFilterChain"



so we add the following beans in our configuration class:

  @Bean
    public AuthenticationManager authenticationManager(AuthenticationConfiguration config) throws Exception {
        return config.getAuthenticationManager();
    }

 @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        return http.csrf(csrf -> csrf.disable())
                .authorizeHttpRequests(auth -> auth.requestMatchers("/auth/welcome", "/auth/addNewUser", "/auth/generateToken","/swagger-ui/**","/swagger-resources/*","/v3/api-docs/**").permitAll())
                .authorizeHttpRequests(auth -> auth.requestMatchers("/auth/user/**").authenticated())
                .authorizeHttpRequests(auth -> auth.requestMatchers("/auth/admin/**").authenticated())
                .sessionManagement(sess -> sess.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
                .authenticationProvider(authenticationProvider())
                .addFilterBefore(authFilter, UsernamePasswordAuthenticationFilter.class)
                
//                .cors((cors) -> cors
//        				.configurationSource(myWebsiteConfigurationSource()))
//                
                .build();
    }

```
@PreAuthorize - Used to authorize method access based on user roles, authorities, or custom logic.
It uses Spring Expression Language (SpEL) for conditions.

----------------------------
Common Expressions
----------------------------

1. hasRole('ROLE_NAME')
   - Example: @PreAuthorize("hasRole('ADMIN')")
   - Note: Spring adds 'ROLE_' prefix automatically

2. hasAuthority('AUTHORITY_NAME')
   - Example: @PreAuthorize("hasAuthority('READ_PRIVILEGE')")
   - Note: No prefix is added automatically

3. hasAnyRole('ROLE1', 'ROLE2')
   - Example: @PreAuthorize("hasAnyRole('ADMIN', 'MANAGER')")

4. hasAnyAuthority('AUTH1', 'AUTH2')
   - Example: @PreAuthorize("hasAnyAuthority('READ', 'WRITE')")

5. !hasRole('ROLE_NAME')
   - Example: @PreAuthorize("!hasRole('GUEST')")

6. isAuthenticated()
   - Example: @PreAuthorize("isAuthenticated()")
   - True if user is logged in (any authentication)

7. isAnonymous()
   - Example: @PreAuthorize("isAnonymous()")
   - True if user is not logged in

8. isFullyAuthenticated()
   - Example: @PreAuthorize("isFullyAuthenticated()")
   - True if not using remember-me login

9. authentication.name
   - Example: @PreAuthorize("authentication.name == 'admin'")

10. Method parameter check
    - Example: @PreAuthorize("#id == authentication.principal.id")
    - '#id' refers to method argument named 'id'

11. Custom method in a bean
    - Example: @PreAuthorize("@securityService.canAccess(#userId)")

----------------------------
Examples
----------------------------

@PreAuthorize("hasRole('ADMIN')")
public void deleteUser(Long id) {
    // Only ADMIN role can delete
}

@PreAuthorize("hasAnyRole('ADMIN', 'MODERATOR')")
public void manageUsers() {
    // ADMIN or MODERATOR can access
}

@PreAuthorize("#userId == authentication.principal.id")
public void viewProfile(Long userId) {
    // Only the owner can view their profile
}

@PreAuthorize("@myService.checkPermission(#orderId)")
public void updateOrder(Long orderId) {
    // Use custom logic to authorize
}
```
