Yesterday, we configured the spring security such that, a default login page came to allow users to login. And there was a browser session automatically remembering if we logged in or not.

But we will not use that login page, because, we are not creating web application, we are creating webservice that is stateless. (REST is stateless) and each request is independent.

so, we are providing login form from ReactJs/ Angular or any front end or from Postman. 

So, we will move to next level.

ie., we are going to authenticate from our controller method.

So that, from reactjs frontend, we call a controller endpoint method to login. or from postman, we call an end point to login.


we need "AuthenticationManger" bean, that can be used to authenticate users login by code.



if all endpoints are allowed access only after logging in, then how we will login? how we will signup??????

	specify what are all the endpoints allowed (permitAll)
	what other urls/ endpoints are authenticated


we specify these in a bean "securityFilterChain"



so we add the following beans in our configuration class:

  @Bean
    public AuthenticationManager authenticationManager(AuthenticationConfiguration config) throws Exception {
        return config.getAuthenticationManager();
    }

 @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        return http.csrf(csrf -> csrf.disable())
                .authorizeHttpRequests(auth -> auth.requestMatchers("/auth/welcome", "/auth/addNewUser", "/auth/generateToken","/swagger-ui/**","/swagger-resources/*","/v3/api-docs/**").permitAll())
                .authorizeHttpRequests(auth -> auth.requestMatchers("/auth/user/**").authenticated())
                .authorizeHttpRequests(auth -> auth.requestMatchers("/auth/admin/**").authenticated())
                .sessionManagement(sess -> sess.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
                .authenticationProvider(authenticationProvider())
                .addFilterBefore(authFilter, UsernamePasswordAuthenticationFilter.class)
                
//                .cors((cors) -> cors
//        				.configurationSource(myWebsiteConfigurationSource()))
//                
                .build();
    }
