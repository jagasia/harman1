```
@PreAuthorize - Used to authorize method access based on user roles, authorities, or custom logic.
It uses Spring Expression Language (SpEL) for conditions.

----------------------------
Common Expressions
----------------------------

1. hasRole('ROLE_NAME')
   - Example: @PreAuthorize("hasRole('ADMIN')")
   - Note: Spring adds 'ROLE_' prefix automatically

2. hasAuthority('AUTHORITY_NAME')
   - Example: @PreAuthorize("hasAuthority('READ_PRIVILEGE')")
   - Note: No prefix is added automatically

3. hasAnyRole('ROLE1', 'ROLE2')
   - Example: @PreAuthorize("hasAnyRole('ADMIN', 'MANAGER')")

4. hasAnyAuthority('AUTH1', 'AUTH2')
   - Example: @PreAuthorize("hasAnyAuthority('READ', 'WRITE')")

5. !hasRole('ROLE_NAME')
   - Example: @PreAuthorize("!hasRole('GUEST')")

6. isAuthenticated()
   - Example: @PreAuthorize("isAuthenticated()")
   - True if user is logged in (any authentication)

7. isAnonymous()
   - Example: @PreAuthorize("isAnonymous()")
   - True if user is not logged in

8. isFullyAuthenticated()
   - Example: @PreAuthorize("isFullyAuthenticated()")
   - True if not using remember-me login

9. authentication.name
   - Example: @PreAuthorize("authentication.name == 'admin'")

10. Method parameter check
    - Example: @PreAuthorize("#id == authentication.principal.id")
    - '#id' refers to method argument named 'id'

11. Custom method in a bean
    - Example: @PreAuthorize("@securityService.canAccess(#userId)")

----------------------------
Examples
----------------------------

@PreAuthorize("hasRole('ADMIN')")
public void deleteUser(Long id) {
    // Only ADMIN role can delete
}

@PreAuthorize("hasAnyRole('ADMIN', 'MODERATOR')")
public void manageUsers() {
    // ADMIN or MODERATOR can access
}

@PreAuthorize("#userId == authentication.principal.id")
public void viewProfile(Long userId) {
    // Only the owner can view their profile
}

@PreAuthorize("@myService.checkPermission(#orderId)")
public void updateOrder(Long orderId) {
    // Use custom logic to authorize
}
```

Monolithic vs Microservices
-------------------------------
Now a days, we are able to book tickets for movies using
	ags website
	book my show app
	
many website, many apps.

All these are different front ends that access an api or back end.

so, we create applications, that can be accessed from any other enterprises using any frontend technologies created in any language or platform

this is not possible if we create a monolithic application

monolithic applications provide all the
	application/ ui
	business logic/ services
	data logic/ services

in a single application/project

if we want to allow third party to access our project, we cannot share the entire project with them.

so, we need to split the application into layers.

frontend can be developed using
	reactjs
	angular
	

backend can be
	one or more restful webservices

this is what microservice architecture suggests.

challenges in this architecture is:

ability to access webservices from each other
and security
and transaction
and many difficulties are there.

But, advantage is parallel production
creating independent services

one service is down, another is not affected.

feign client
	is used to allow one service to call another

eureka service discovery
	is used to monitor the services status up or down and health

api gateway
	the public need not know all the url, 
	let them know only the url of gateway. and based on the end 		point, gateway shall call the corresponding service.

load balancer
	we can have multiple services, we will distribute the load, by evenly calling different services. We can clone the services and deploy them in different geographical locations and use load balancer to choose different clone of the service evenly.

circuit breaker
	when a service is down, we want to exit the circuit just like exception handling, using fallback method.

import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.PutMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.ResponseStatus;

import com.harman.demo.Product;

@FeignClient(name = "product-api", url = "http://localhost:5000/product")
public interface ProductApi {

	@PostMapping
	@ResponseStatus(value = HttpStatus.CREATED)
	public Product create(@RequestBody Product product);
	
	@GetMapping
	public ResponseEntity<List<Product>> read();
	
	@GetMapping("/{id}")
	public Product read(@PathVariable("id") Long id);
	
	@PutMapping("/{id}")
	public Product update(@PathVariable Long id, @RequestBody Product product);	

	@DeleteMapping("/{id}")
	public ResponseEntity<Product> delete(@PathVariable Long id);
	
	@GetMapping("/category/{category}")
	public List<Product> findByCategory(@PathVariable String category);
	
	@GetMapping("/range/{from}/{to}")
	public List<Product> findProductsInRange(@PathVariable("from") Double from,@PathVariable Double to);
}

package com.example.demo;

import java.util.Arrays;
import java.util.List;

import org.springframework.cloud.client.DefaultServiceInstance;
import org.springframework.cloud.client.ServiceInstance;
import org.springframework.cloud.loadbalancer.core.ServiceInstanceListSupplier;

import reactor.core.publisher.Flux;

class DemoInstanceSupplier implements ServiceInstanceListSupplier {
    private final String serviceId;

    public DemoInstanceSupplier(String serviceId) {
        this.serviceId = serviceId;
    }

    @Override
    public String getServiceId() {
        return serviceId;
    }

    @Override
        public Flux<List<ServiceInstance>> get() {
          return Flux.just(Arrays
            .asList(new DefaultServiceInstance(serviceId + "1", serviceId, "localhost", 8081, false),
              new DefaultServiceInstance(serviceId + "2", serviceId, "localhost", 8091, false)));
    }
}
