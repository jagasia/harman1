Rest parameters:
	similar to param array
	normally, an array, passed as an argument, is passed by reference.
	but a param array, can pass array as argument but as values
	so, the function that affects the parameter array, does not
	affect the actual parameter array

function fn1(arr)
	if arr is modified inside the fn1 function, 
	what happens to the actual parameter

fn1(arr1)

if paramter is a rest parameter, then a copy of the array is passed as argument.

function fn1(...arr){
    //affect the values of arr
    arr[0]=100;
}
var arr=[1,2,3,4];
fn1(arr);

console.log(arr[0]);		//still it is 0


Rest parameters can also be passed values instead of array

fn1(2,1,7,4);		//values instead of array

Javascript ES6 features:
====================

JavaScript ES6 (ECMAScript 2015) introduced many new features that modernized the language and made it more powerful and expressive. Here’s a breakdown of the most important ES6 features:

---

### 🔹 1. **Let and Const**

* `let`: Block-scoped variable.
* `const`: Block-scoped constant (cannot be reassigned).

```js
let x = 10;
const y = 20;
```

---

### 🔹 2. **Arrow Functions**

Shorter syntax for functions and lexically binds `this`.

```js
const add = (a, b) => a + b;
```

---

### 🔹 3. **Template Literals**

Multi-line strings and embedded expressions using backticks (`` ` ``).

```js
const name = "Alice";
const greeting = `Hello, ${name}!`;
```

---

### 🔹 4. **Destructuring Assignment**

Extract values from arrays or objects into variables.

```js
const [a, b] = [1, 2];
const {name, age} = {name: "Bob", age: 30};
```

---

### 🔹 5. **Default Parameters**

Set default values for function parameters.

```js
function greet(name = "Guest") {
  return `Hello, ${name}`;
}
```

---

### 🔹 6. **Rest and Spread Operators**

* `...rest`: Combines remaining elements into an array.
* `...spread`: Spreads elements from an array or object.

```js
function sum(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}

const arr = [1, 2, 3];
const newArr = [...arr, 4];
```

---

### 🔹 7. **Enhanced Object Literals**

Shorthand property names and methods.

```js
const x = 10;
const obj = {
  x,
  greet() {
    return "Hello";
  }
};
```

---

### 🔹 8. **Classes**

Syntactic sugar over prototype-based inheritance.

```js
class Person {
  constructor(name) {
    this.name = name;
  }
  greet() {
    return `Hi, I'm ${this.name}`;
  }
}
```

---

### 🔹 9. **Modules**

Import and export functions, objects, or primitives.

```js
// module.js
export const PI = 3.14;

// main.js
import { PI } from './module.js';
```

---

### 🔹 10. **Promises**

A native way to handle asynchronous operations.

```js
const fetchData = () => {
  return new Promise((resolve, reject) => {
    setTimeout(() => resolve("Data received"), 1000);
  });
};
```

---

### 🔹 11. **Map and Set**

New data structures for unique values and key-value pairs.

```js
const set = new Set([1, 2, 3]);
const map = new Map([['a', 1], ['b', 2]]);
```
