What is a component?
-------------------------
a component is a re-usable code that can be plugged or moved or removed or customized easily in an application.

a component can have any of or all of the following:
	html
	css
	ts		(mandatory)
	spec.ts

a component must have a .ts file.

how can we create a component in angular?
	ng g c <<component name>>
	ng generate component <<component name>>

ex:
	ng g c counter

in angular,
a component is a class that is decorated by @Component decorator.

in java, do you know annotations?
in angular, they are called as decorators.
ex:
	@Component

import { Component } from '@angular/core';






lets decode this app component:

import { Component } from "@angular/core";

@Component({
  selector: 'app-root',
  imports: [],
  templateUrl: './app.html',
  styleUrl: './app.css'
})
export class App {
  protected title = 'first-app';
}



templateUrl
or
template


styleUrl
or
styleUrls



selector:		specify the tagname, that is used to plug this component



  selector: 'app-root',

if selector is app-root, then plug this component, wherever you want using:

	<app-root></app-root>

Binding
---------
what is binding?
	associating a variable or expression to a property or many things
there are various types of binding:

property binding
event binding
two way data binding
style or class binding
attributes binding



Property binding
--------------------
A property in html code will be bound to a variable in ts code

1 way, not vice versa.

whatever the value of the variable changes, they are reflected in the html element's attribute



<input type="text" name="" id="" value="Hello">

there is no binding in above text box.

but, if i use following code:

<input type="text" name="" id="" [value]="title">

by using [], we mean, that we are passing value to this property, but
we are passing variable to this property. So "title" is not value, it is variable
