Spring cloud gateway
-------------------------
	we are going to provide on microservice that is going to be the single point for all clients. This gateway will redirect the request to other microservices based on the "path" they choose.

for example:
	there are 3 microservices running and their endpoints are

http://localhost:8081		for customer
http://localhost:8082		for product
http://localhost:8083		for sale

but instead of allowing users to discover these microservices by themselves, we are providing a gateway that runs in 8080

gateway runs in 8080

user input:
	http://localhost:8080/customer
	http://localhost:8080/product
	http://localhost:8080/sale


this 1 gateway, is receiving all requests and redirect to corresponding service.
