lets see how we can run a docker image
---------------
for example

if you do not have mysql in your computer.
we can pull and run mysql image from docker hub.


### ✅ **Step 1: Pull MySQL 8 Docker Image**

```bash
docker pull mysql:8
```

---

### ✅ **Step 2: Run MySQL 8 Container**

```bash
docker run -d \
  --name mysql8-container \
  -e MYSQL_ROOT_PASSWORD=root123 \
  -p 3306:3306 \
  mysql:8
```

**Explanation:**

* `-d`: Run in detached mode.
* `--name mysql8-container`: Container name.
* `-e MYSQL_ROOT_PASSWORD=root123`: Set root password.
* `-p 3306:3306`: Expose port 3306 to host.

---

### ✅ **Step 3: Access Container Bash**

```bash
docker exec -it mysql8-container bash
```

Once inside the container, you'll see a bash prompt like:

```bash
root@<container_id>:/#
```

---

### ✅ **Step 4: Login to MySQL from Inside Bash**

```bash
mysql -u root -p
```

Then enter the password you set earlier (`root123` in this example).

---

### ✅ **Optional: View Running Containers**

```bash
docker ps
```

---

### ✅ **Stop the Container (When Done)**

```bash
docker stop mysql8-container
```

---

### ✅ **Start Again (If Already Created)**

```bash
docker start mysql8-container
```
